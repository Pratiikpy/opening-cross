# @opening-cross/treasury-client

Generated `@solana/kit` client for the `treasury` program: a program-custodied treasury with a periodic spend allowance, attestation-gated release and holder liquidation (ADR-0014).

```sh
npm install @opening-cross/treasury-client
```
