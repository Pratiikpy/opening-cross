# ADR-0002: Licence

Date: 2026-10-05 · Status: accepted

## Decision
Apache-2.0 for all code in this repository. Opening Cross is meant to be an open standard other venues adopt; Apache-2.0 is permissive and carries an explicit patent grant, which matters for an exchange mechanism.

## Constraint
Meteora programs (non-commercial licence) and MetaDAO (BSL 1.1) are called through their deployed programs and published SDKs, never copied into this repository.
