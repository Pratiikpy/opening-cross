PROJECT DESCRIPTION  (paste everything below this line)

𝗢𝗣𝗘𝗡𝗜𝗡𝗚 𝗕𝗘𝗟𝗟: 𝗧𝗛𝗘 𝗙𝗔𝗜𝗥 𝗙𝗜𝗥𝗦𝗧 𝗣𝗥𝗜𝗖𝗘 𝗙𝗢𝗥 𝗘𝗩𝗘𝗥𝗬 𝗡𝗘𝗪 𝗠𝗔𝗥𝗞𝗘𝗧, 𝗦𝗘𝗔𝗧𝗘𝗗 𝗢𝗡 𝗠𝗘𝗧𝗘𝗢𝗥𝗔

A new market's first minute is a race, and the fastest wins. Pine Analytics found that over half of pump.fun tokens are sniped in the block they are created, and Memento Research found 84.7% of 2025 launches (100 of 118) trade below their launch valuation. Opening Bell replaces the race with a call auction, then hands the result to Meteora.

𝗛𝗢𝗪 𝗜𝗧 𝗪𝗢𝗥𝗞𝗦
1. Orders are escrowed on chain during a call window. Bids can be sealed (commit then reveal), so nobody sees a price to jump ahead of.
2. At the close, one clearing price P* is found where demand meets supply. Every filled order pays P*. Unfilled money is refunded, and anyone can trigger settlement.
3. The market then opens on Meteora at exactly P*, so the first trade starts where the auction ended.

𝗪𝗛𝗔𝗧 𝗪𝗘 𝗕𝗨𝗜𝗟𝗧 𝗢𝗡 𝗠𝗘𝗧𝗘𝗢𝗥𝗔 (all driven by real CPIs into Meteora's own deployed programs, proven on Solana devnet)
• 𝗗𝗕𝗖: our program creates the issuer's pre-committed curve with the transfer hook variant and the pool's start price must equal sqrt(P*) to within one unit, or the program refuses. Mint authority is handed to the cross, tokens are minted at P*, and mint authority is None after finalize. 𝗪𝗛𝗬 𝗜𝗧 𝗜𝗦 𝗧𝗘𝗖𝗛𝗡𝗜𝗖𝗔𝗟𝗟𝗬 𝗗𝗜𝗙𝗙𝗘𝗥𝗘𝗡𝗧
• One clearing rule in a no_std Rust crate shared by the program and a conformance generator: an independent TypeScript implementation reproduces all 525 vectors, and the program reproduces the 523 it can represent on LiteSVM, with 0 mismatches.
• A stranger can check any cross: the verifier recomputes it from its on-chain book. Sweep of every devnet cross: 38 verified, 0 mismatched, 10 not yet cleared.
• Scale: 100,000 real orders at 21,633 compute units each, settled in 33 transactions.
• Everything is an API and an SDK, plus a Rust CPI crate and an MCP server, so any launchpad or agent can use the cross as its front door.
