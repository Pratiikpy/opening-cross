# W2C-S10 (and L6 partly): trade from a link

Outcome: **BUILT** for the action endpoints and the cross page; webhooks (L6) are not built; no blink client was available to render the action. Design: ADR-0404. Code: `services/api/src/routes/holder-actions.ts`, `components/cross/holder-readiness.tsx` (`ShareAsBlink`).

The endpoints follow the Solana Actions specification (https://solana.com/docs/advanced/actions, read for this work): `GET /v1/actions/crosses/:address` answers `type: action`, an absolute `icon`, `title`, `description`, `label`, and `links.actions` with a two-parameter form (`price`, `quantity`); `POST .../bid?price=&quantity=` with `{ account }` answers `type: transaction`, the base64 transaction and a `message` that states the escrow. Errors are `{ message }`. A sealed, not-yet-open, closed or settled cross answers `disabled: true` with the reason.

Tests: `holder-actions.test.ts` (5 tests of the Actions part): metadata and href, the disabled reasons, the error shape for a non-cross and a junk address, the decoded transaction (fee payer is the bidder, one `cross_core` instruction), eleven refusals (off-grid price, junk numbers, zero and negative quantity, missing parameters, no account, sealed, not open yet, closed, after the close), and the missing `WEB_URL`.

Devnet run (`holder-sponsor-live.mjs`, cross `8WGU…aAj6`): the action endpoint built a bid transaction (`Bid for 1 tokens at up to 1.3 each. Up to 1.3 is held in escrow…`). In the browser (`holder-pages-flow.mjs`): the cross page shows the `solana-action:` link and "Check what it answers" returns the cross as an action.

Not covered: a blink-aware wallet or feed rendering the form and signing; the specification's CORS minimum is met by the API's global CORS for GET and POST, but the API advertises `GET, POST`, not the specification's `GET,POST,PUT,OPTIONS` (a one-line change to the CORS setup in `server.ts`, listed in the report); `actions.json` (not needed when the action link names the API); a widget iframe (the cross page is embeddable as it is).
