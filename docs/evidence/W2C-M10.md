# W2C-M10 (with M11): a WCAG 2.2 AA audit over every route

Outcome: **BUILT** (the tool, the run, and the fixes for every finding in a holder-side or shared metric file). Method: ADR-0413. Tool: `apps/web/e2e/holder-audit.mjs` (axe-core 4.13 through `@axe-core/playwright`, rule tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa` and best-practice; the 2.2 set adds target size and focus-not-obscured). Raw results: `docs/evidence/W2C-M10-audit.json` (every page load with its violations and problems) and `W2C-M10-audit-recheck.json` (after the fixes).

Scope: every `page.tsx` under `apps/web/src/app`, with real addresses for the dynamic routes (a finalized cross, a live cross, a treasury, a receipt for a wallet that traded), 38 routes, at 1440 and 390, light and dark, on a production build (`next build` then `next start`; the development server adds its own overlay): 152 page loads. Each load also records console errors, page errors, failed requests and HTTP errors; HTTP 429 answers from the shared public cluster are counted apart (none occurred).

First run: 123 of 152 loads clean. Findings and what was done:

| Route | Finding | Cause and fix |
|---|---|---|
| `/accuracy`, `/` | `definition-list` (serious): `<dl>` with `div > p` | `components/metrics/metric-card.tsx` put paragraphs in a definition list. They are `dd` now (also the error card). |
| `/accuracy` | `heading-order`: an h3 straight after the h1 | the window headings are h2 in `app/accuracy/page.tsx`. |
| `/export` | `landmark-unique`: a section and a table region shared a name | the region is "Table of public figures". |
| `/markets` (found earlier, in the flow run) | `landmark-unique` | same cause, same fix. |
| `/issue`, `/issuer/accelerators`, `/issuer/qa/<cross>`, `/issuer/simulator` | HTTP 404 from `/v1/issuer/*` on the live API | not a page fault: the issuer pages (another workstream) call routes the deployed API does not carry yet. They need the API deployed with the issuer routes. |
| a live cross | one navigation timeout of 60 s on the first load | not reproduced: 4 of 4 clean on re-run. |

Re-run of `/`, `/accuracy`, `/export`, `/markets`, `/orders`, `/portfolio`, `/rights` and the live cross: 0 findings in all four configurations. The 404s on the issuer routes were not re-run because the cause is the deployment.

Screenshots read (`screens/w2c/audit/`, one light desktop and one dark phone per route): alerts, portfolio, markets, practice, a cross, the home page. Observations acted on: the markets table hid two secondary columns on a phone, the stocks block stopped printing fifty empty rows, the cohort index stopped printing a level for one token.

## Not covered (axe cannot decide these, and nothing here claims them)

Keyboard order and traps through every flow (the flow scripts use the keyboard only where noted), focus not obscured by the sticky header in the middle of a flow (the scroll padding exists and axe's check passes), meaning and reading level of every sentence, screen reader announcement quality (live regions are used for status and errors but were not listened to), motion preferences, zoom to 400% and text scaling, and states reachable only with a wallet (the claim center and the order ticket were scanned in the live runs: `W2C-Z6.md`, `W2C-I6.md`). A passing axe run is not WCAG conformance.
