# W3D-R3: upstream contributions (decision: human)

Outcome: **HUMAN.** ADR-0662. Row R3.

A contribution is a pull request from a person's GitHub account to a repository of another organisation, accepted or not by its maintainers under their licence. No program, client or test in this repository changes it. The ADR lists what the repository holds that a person could offer, and says that which of it Meteora's maintainers would take is theirs to decide.
