# A10 issuer dashboard (2026-10-13)

Outcome: BUILT for raise status, holder register, treasury, fees, disclosure schedule and Q&A. Liquidity health is NOT built (no pool read in the API).

## What exists

`/issuer` (`components/issuer/issuer-overview.tsx`, `lib/issuer-dashboard.ts`): "Needs you" tasks derived from the data; the issuer's own crosses (`/v1/crosses/summary` filtered by creator); for the selected cross the raise status (orders, indicative or cleared price, tokens, window and a clear line that nothing can change the price), the fees it paid computed with the program's formula, and the holder register (the wallets that bid and what each received, CSV download, "not a list of current holders"); the issuer's treasuries (vault, allowance left, disclosure state); `/issuer/disclosures` (post updates, answer holders), `/issuer/qa/[address]` (a public thread that anyone can ask in).

## Checks

- `apps/web/test/issuer-dashboard.test.ts` (12): own crosses, the register (sellers excluded, escrow and fill sums, pending before settlement, CSV with units and quoting), the fee formula (notional rounded up, protocol share of the total), and every task (a treasury offered once per launched coin and only when none exists, overdue disclosure and questions first, lapsed attestation, the cross not yet open or taking orders by the clock).
- Browser (`e2e/issuer-console.mjs`, run 1 and 8): without a wallet the page asks for one and shows nothing; the issuer's cross is listed and selected; raise status and an empty register are shown (no invented rows); a holder's question about the issuer's cross appears for the issuer as waiting; only the creator can answer; the stored thread shows the answer. Screens: `console-01-overview.png`, `console-08-questions.png`.

## Not covered

- Liquidity health: the API has no read of pool state after settlement; the page says so.
- A settled cross with fills: the devnet crosses created in this session are still open; the register arithmetic is covered by unit tests and an earlier finalized cross's orders were not browsed here.
- Insider declarations and lockups in the register (VM7, B12): not in the programs deployed.
