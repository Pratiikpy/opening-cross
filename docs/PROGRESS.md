- **A real concurrency defect, found by measuring (DP13).** A devnet run with ten bids in flight had 39 of 40 fail with WrongShard: the shard was `order_index % shards`, so every bidder who read the cross before another bid landed computed the wrong one. The shard is now `sha256(owner ‖ nonce)` modulo the shard count in the program, SDK and CPI crate; devnet cross_core upgraded; the same run now lands 40 of 40 and 80 bids settle to the reference price. 100,000 real orders settle in 33 transactions at 21,633 CU per bid (`docs/evidence/DP13-scale.md`). Not met: p90 landing latency 17.7 s on the public devnet endpoint against a 5 s target (NOT VERIFIED on a paid RPC).
